FoundationsThe one law, built once — the shared physics every other explorable here assumes

Everything in this library rests on a single idea: a coherent system is a network of coupled oscillators whose connections are alive, and left to run by their own rule they climb a quantity we call coherence capital. This is where that idea is built from nothing, interactively, so the other essays can simply point here instead of repeating it.

Five short, self-contained chapters. By the end you will have dragged oscillators into sync, watched a network discover that pure unison is death, met the local rule that grows connectivity by what coheres, seen why coherence has an arrow the way entropy does, and watched a substrate store a memory as the shape of a landscape and recall it by settling. Nothing here requires graduate physics; every term is built before it is used.
